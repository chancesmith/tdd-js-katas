## TDD Katas

## setup

1. Install Node.js 25.7.0 (use `mise install`, `nvm install`, or your preferred Node version manager - version is in `.node-version`)
1. `yarn install`
1. `yarn test` to run Jest (JavaScript katas)
1. `yarn test:ts` to run Jest with TypeScript katas

## TypeScript Setup

TypeScript katas are located in directories with the `_TS` suffix (e.g., `src/7_Gardening_TS/`).

The project includes:
- TypeScript configuration (`tsconfig.json`)
- ts-jest for running TypeScript tests
- Type definitions for Jest
